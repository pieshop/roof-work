# Roof Options, Solar And Cost Position

## Current Roof Evidence

Evidence discovered on 08/09/2026 made complete roof replacement a leading option:

- Original approximately 1900s slate roof
- Approximately 120 years old
- No roofing underlay
- Visible gaps/daylight through roof
- Confirmed intermittent rainwater ingress
- Roofcraft has inspected the roof in person

The absence of underlay is consistent with the age of the roof and is not by itself evidence of failure. However, because there is no underlay, failed/slipped/missing slates provide no secondary weather barrier.

## Option 1: Repair / Overhaul Existing Roof

Local repairs to slipped/broken slates, flashings, ridges and related defects while leaving the roof substantially in place.

This was originally the baseline assumption behind the £12,000-£18,000 whole-project repair estimate.

Following discovery of active leaks and Roofcraft's inspection, this option is becoming less attractive unless other experienced roofers independently conclude the roof remains worth preserving in place.

## Option 2: Strip And Re-Slate Using Existing Slates

Potential approach:

1. Strip existing slates.
2. Sort and salvage sound slate.
3. Inspect roof timbers.
4. Install modern breathable membrane.
5. Install new treated battens.
6. Re-slate with salvaged originals.
7. Make up shortfall using matching reclaimed slate.

This was previously considered an attractive middle option.

However, Ben from Roofcraft strongly recommended against reusing the existing slates after inspecting the property.

Slate reuse should therefore no longer be treated as the preferred option unless another experienced slate roofer provides a convincing independent reason to recommend it.

## Option 3: Complete Roof Replacement

This is now the leading working option, subject to written quotations and further independent contractor opinions.

Likely scope:

- Strip existing roof
- Dispose of or otherwise deal with existing slate
- Inspect exposed roof timbers
- Repair timbers as required
- Install modern breathable roofing membrane
- Install new treated battens
- Install new roof covering
- Renew ridge/abutment/flashing details as required
- Coordinate chimney removal/making-good
- Coordinate structural high-level works
- Potentially coordinate solar mounting requirements while scaffold is present

## Natural Slate Vs Concrete

Ben indicated that concrete tiles may be easier/better for future solar panel installation.

Natural slate remains a viable option for solar if suitable slate-specific mounting systems are used.

The approximately £2,000 price difference is relatively small compared with the overall reroof cost, so the choice should consider:

- Appearance
- Structural loading
- Solar installation
- Longevity
- Materials
- Future maintenance
- Guarantee
- Character of the original house

A particularly important issue is weight. Concrete tiles can be significantly heavier than natural slate.

Given the existing purlin/gable structural issues, changing from slate to concrete should not happen without confirming that the existing roof structure is appropriate for the increased dead load. This should ideally be confirmed by the contractor and/or the structural engineer.

## Solar PV

Stephen is interested in installing solar panels.

Because a complete reroof is now likely, solar should ideally be considered before roof works begin.

Potential advantages:

- Coordinate panel layout
- Coordinate mounting positions
- Avoid unnecessary later disturbance to the new roof
- Use existing scaffolding
- Plan cable routes
- Plan inverter/battery position
- Ensure roof covering and mounting system are compatible

Ben from Roofcraft has confirmed that coordinating roofing and solar mounting requirements is not a problem.

Do not choose concrete tile solely because it is easier for solar. Natural slate is compatible with solar using appropriate mounting systems.

The important decision is:

**Natural slate + solar** versus **concrete tile + solar**

rather than simply **natural slate** versus **concrete**.
